IT Helpdesk Simulation Lab

Overview

This project simulates real-world IT support scenarios using a Windows virtual machine environment.

The goal is to demonstrate practical helpdesk skills such as:

* User account management
* Permission configuration
* Troubleshooting access issues
* Password resets

Environment

* Windows 11 VM (UTM on Apple Silicon)
* Command Prompt (CLI tools)
* Local Users and Groups
* File system permissions (NTFS)

Simulated Scenarios

* Unauthorized folder access
* Password reset requests
* Access denied troubleshooting
* User/group permission management

Project Structure

* tickets/ → documented troubleshooting cases
* screenshots/ → supporting evidence

⸻

Skills Demonstrated

* Windows system administration
* Troubleshooting methodology
* Access control & permissions
* Basic helpdesk operations

Status

In progress – actively adding new support scenarios.
